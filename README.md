# Valea.bg → Temu Excel scraper

Скрейпърът чете публикуваните продукти от Valea.bg и попълва качения Temu Excel шаблон.

## Какво прави

- използва публичния WooCommerce Store API на Valea, а не чупливи CSS селектори;
- създава отделен ред за всяка конфигурирана комбинация от размери;
- обединява чашка и подгръдна обиколка, например `F + 65 → 65F`;
- преобразува категориите на Valea към категориите в Temu шаблона;
- попълва описания, снимки, SKU, цвят, цена, наличност, пакетни размери и GPSR полета;
- попълва състава: Polyamide 80%, Elastane 10%, Cotton 5%, Polyester 5%, а останалите полета за влакна — с 0;
- разделя резултата автоматично на части до 1900 реда;
- запазва формулите, падащите менюта, условното форматиране и скритите листове на оригиналния Temu файл.

## GitHub Actions — препоръчителен начин

1. Създай ново GitHub repository.
2. Качи цялото съдържание на тази папка, включително скритата папка `.github`.
3. Отвори **Actions → Valea to Temu scraper → Run workflow**.
4. За кратък тест въведи `3` в **Product limit**.
5. След завършване свали artifact-а **valea-temu-results**.

При празно поле **Product limit** се обработват всички продукти.

## Стартиране на Windows

Нужен е Python 3.10 или по-нов. Стартирай `run.bat`. Резултатите ще бъдат в папка `results`.

Кратък тест само с Jennifer Soft:

```powershell
python scraper.py --search "Jennifer Soft" --limit-products 1
```

Тест на правилата за категориите, размерите и цветовете:

```powershell
python -m unittest discover -s tests -v
```

## Настройки

Всички постоянни стойности са в `config.json`:

- `base_price_factor: 0.89` — Base Price е 89% от текущата цена на Valea;
- `default_quantity: 100` — количество за публикувана налична вариация;
- размери и тегло на пакета;
- `shipping_template: "Офис"` — стойността, която вече присъства в качения Temu шаблон;
- `manufacturer: "VALEA BG 10 Ltd"` — стойността, която вече присъства в качения Temu шаблон;
- `max_rows_per_file: 1900` — безопасно под лимита на Temu от 2000 реда.

## Важно за размерната таблица

Valea не предоставя официални мерки на продуктите през публичния си API. Тъй като Temu маркира размерните измервания като задължителни, скрейпърът попълва консервативни стойности според размера. Те са събрани на едно място във функцията `size_measurements()` и трябва да бъдат заменени с официалната таблица на производителя, ако разполагаш с нея.

Полето **EU Responsible person** остава празно, защото производителят е в България (ЕС) и според указанието в самия Temu шаблон отговорно лице не е необходимо при производител в ЕС.
